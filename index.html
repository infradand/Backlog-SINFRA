General

Secciones y áreas (orden fijo de la vista Semanas)

Supabase · base en línea (recomendado)

Con esto los datos viven en la nube: al abrir la app se cargan desde Supabase, cada cambio se sube solo y todos los que abran la página ven lo mismo. El navegador queda solo como copia de respaldo.
SQL a ejecutar una vez en Supabase → SQL Editor (crea la tabla y permite leer/escribir con la clave anon):
create table if not exists backlog_sinfra (id text primary key, data jsonb not null, updated_at timestamptz default now());
alter table backlog_sinfra enable row level security;
create policy "anon_all" on backlog_sinfra for all to anon using (true) with check (true);

GitHub (guardado de datos como JSON en el repositorio)

Archivos: backlog.json, config.json, calendarios.json. El token necesita permiso de contenido (repo) sobre ese repositorio.

Importar matriz de criticidad (Excel)

Elige el archivo y la hoja; mapea las columnas una vez (queda guardado). Si la tarea ya existe (mismo ID de matriz u OT/aviso) se actualiza en vez de duplicarse.

Importar calendario de detención (Excel/CSV)

Tabla con columnas equipo, fecha, turno y horas, o el formato bisemanal (matriz con filas “HORAS DETENCIÓN”). Cada carga queda como versión con su fecha; cuando hay bisemanal para una semana, reemplaza al mensual.

Reunión · bolsas de capacidad (personas por día) y grupos

Cada sección pertenece a un grupo (Total piping / Total chancado / Total concentrador). Los subtotales de la pestaña Reunión comparan las personas asignadas por día y turno contra la bolsa del grupo.
